# Project 1 - Data Cleaning

This project focuses on data cleaning and preprocessing using Python and Pandas.
📌 Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship Program (Batch 2026). The primary objective of this project is to perform Exploratory Data Analysis (EDA) on an e-commerce dataset to uncover meaningful insights, trends, patterns, and anomalies using Python.

The project focuses on transforming raw transactional data into actionable business insights through analytical techniques and data visualization.

🎯 Objective

The goal of this project is to:

Analyze customer purchasing behavior Identify sales trends and patterns Detect outliers and anomalies Perform descriptive statistical analysis Generate business insights from raw data Build analytical thinking using real-world datasets 🛠 Technologies Used Python Pandas NumPy Matplotlib Seaborn JupyterLab 📂 Dataset Information

The dataset contains e-commerce transactional records including:

Order IDs Customer IDs Product details Quantity purchased Unit price Total revenue Payment methods Order status Shipping information Referral sources Transaction dates 📊 Exploratory Data Analysis Performed

Data Inspection Dataset overview Data types analysis Shape and structure validation
Descriptive Statistics Mean Median Count Standard deviation Minimum and maximum values
Missing Value Analysis Identification of null values Missing data percentage analysis
Duplicate Analysis Duplicate row detection Unique identifier validation
Product Analysis Most sold products Product sales distribution
Revenue Analysis Revenue generated by each product Product-wise revenue comparison
Payment Method Analysis Most preferred payment methods Payment behavior patterns
Order Status Analysis Delivered orders Returned orders Cancelled orders Pending orders
Trend Analysis Order trends over time Transaction activity analysis
Outlier Detection Identification of unusual transaction values Boxplot analysis for TotalPrice
Correlation Analysis Relationship between numerical variables Correlation heatmap visualization 📈 Key Insights Certain products generated significantly higher revenue than others. Customer purchasing behavior showed clear transactional patterns. Some payment methods were more commonly used by customers. Order trends varied across different time periods. Outliers were identified in transaction amounts, indicating unusually large purchases. 📉 Visualizations Included
The project includes multiple professional visualizations such as:

Bar Charts Line Charts Boxplots Correlation Heatmaps

These visualizations were used to better understand trends, distributions, and relationships within the dataset.
