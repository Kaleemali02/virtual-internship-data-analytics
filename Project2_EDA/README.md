# Project 2 - Exploratory Data Analysis

This project performs EDA using Python, Pandas, and Matplotlib.
📊 Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship Program (Batch 2026). The primary objective of this project is to perform a professional Exploratory Data Analysis (EDA) on an e-commerce transactional dataset to uncover hidden patterns, trends, distributions, and business insights using Python.

The project focuses on transforming raw business data into meaningful analytical insights through descriptive statistics, visualization, and analytical reasoning.

🎯 Project Objective

The goal of this project is to:
